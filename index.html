Things I've built

Featured · 2026

Payment Gateway Simulator

An event-driven card payment gateway built as four Spring Boot microservices. It covers the full money flow: merchant onboarding, card tokenization, authorize / capture / void / refund, Kafka event streaming, a ledger, and nightly settlement.

  • Idempotency keys: retried requests never double-charge
  • Transactional outbox: no lost events between Postgres and Kafka
  • AES-GCM card vault: raw card numbers never leave tokenization
  • Spring Batch settlement with an idempotent Kafka consumer and dead-letter topic
